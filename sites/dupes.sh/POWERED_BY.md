# Hosted attribution footer

All hosted Feedback HTML pages except `/admin` and its children receive an unobtrusive footer, including widgets, roadmap, changelog and public post views. Hosted Forms `/f/:id` and `/f/:id/embed` receive it too; it remains outside the client-rendered app so questions, endings and errors do not remove it. The demo uses the same hosted path. Self-hosted rendering and API/JSON responses are unchanged.

The exact label is **Powered by Dupes**, linking to `https://dupes.sh/?utm_source=badge&utm_medium=board&utm_content=<instance-id>`. The link opens a new tab with `noopener`, including in embeds. The absolute URL survives Feedback's base-path link rewriting. The stylesheet is served by the existing tenant router under `/assets/powered-by.css`; no inline CSS or script weakens CSP. It is a normal page footer, not a floating overlay, and stays visible on mobile and widgets.

Apply only site `0007_powered_by.sql` to the combined Worker database, not the parallel standalone platform `0005_powered_by.sql`. The migration adds `instances.powered_by`, checked boolean, non-null, default 1 for existing and new instances. Demo resets preserve this instance setting. A future paid entitlement can set it to zero server-side. There is no public setting, API field or UI to turn it off today. No new secret, provider, binding or cron change is needed.

Existing cookieless daily source counts record successful human-like HTML landing requests under source `badge`. Repeat page views count again; this is not a unique-human or click-event counter. `utm_content` carries the instance identifier on the link, but existing analytics deliberately discards query strings, so per-instance referral reports are not added. Operator stats retain their current authentication and privacy behavior.
